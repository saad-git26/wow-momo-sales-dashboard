# WOW Momo Store Sales Dashboard
    An interactive Power BI dashboard that analyses sales performance of a momo store
and turns raw sales data into clear, actionable insights.

# Objective
    To understand which products drive revenue, how sales change over time,
and where the business can improve.

# Dataset
- Source: Online + Dummy data

# Tools Used
- Power BI (dashboard and visuals)
- Excel (data cleaning and preparation)

# Dashboard Features
- Sales trend by day / month
- Top items and category-wise sales
- Interactive slicers for date and category

# How to Open
Download the `.pbix` file and open it in Power BI Desktop.
